# Contributing to The Drift 8B-44

The site grows through Pull Requests. You do not need local Git or Jekyll to contribute.

## Fast path

| Add | Copy | Save in |
|---|---|---|
| Experience | `templates/experience.md` | `_experiences/short-name.md` |
| Character | `templates/character.md` | `_characters/character-name.md` |
| Tip or trick | `templates/tip.md` | `_tips/short-name.md` |
| Docs improvement | edit the page | `docs/` |

### 1. Fork the repository

Use GitHub's **Fork** button.

### 2. Copy a template

Open `templates/`, copy the closest template, and create a new Markdown file in the matching collection.

Use lowercase filenames with hyphens.

### 3. Fill in the front matter

Every community entry begins with a small YAML block. Keep the field names and replace the example values.

### 4. Add media if useful

Small community images can go under:

`assets/images/community/<github-username>/`

Only submit media you have the right to share.

### 5. Open a Pull Request

Suggested titles:

- `experience: add market under the ring`
- `character: add vespera`
- `tip: recovering a scene`
- `docs: clarify continuity`

Explain what you added and link related entries when useful.

## What merge means

A merged PR means the contribution is accepted into this public archive.

It does **not** mean that a personal experience, character history, interpretation, or continuity becomes mandatory for every other Drift session.

## Updating a character

Edit the existing file and open another PR. Git keeps the complete revision history.

## Keep contributions useful

- Record what happened or what worked.
- Distinguish observations from theories when relevant.
- Do not rewrite somebody else's character without permission.
- Tips are recommendations, not universal rules.
- Prefer useful detail over invented bureaucracy.
