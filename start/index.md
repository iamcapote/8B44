# Start

The Drift is player-driven. You can explore, continue something you care about, experiment with a character, or begin without carrying continuity forward.

1. **Say what you want to do.** You are not limited to a fixed menu.
2. **Redirect freely.** If a character, place, image, or direction is not working, change course.
3. **Preserve only the continuity you care about.** Persistence is available when useful; it should not become a cage.
4. **Keep what is worth keeping.** Characters, discoveries, memorable sessions, and useful techniques can be added to this archive.
5. **Treat community material as history and possibility.** It is not a mandatory campaign path.
