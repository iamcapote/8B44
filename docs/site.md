# What is the 8B-44 site?

8B-44 is the public community layer around The Drift.

It can hold characters, session records, discoveries, screenshots, community art, tips, tricks, play techniques, guides, and maintained documentation.

It is intentionally static. GitHub is the write system: contributions arrive as Pull Requests, and merged Markdown becomes part of the published site.

## What it is not

This site is not a replacement for The Drift's narrator, procedural generation, memory, or runtime.

The repository records selected outputs from experiences. It should not unnecessarily constrain what remains possible in future experiences.
